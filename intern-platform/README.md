## 事業の前提（口頭指示の整理）

- 収益モデルは **成果報酬型**（長期インターン採用決定ベース）。接点課金は単価的に成立しない
  （新卒紹介: 採用単価 100〜200万円 → 接点単価 1〜2万円が成立 / インターン: 採用単価 15万円前後が相場感）
- **営業人員を介さない自走型（セルフサーブ）** のサービスモデルを志向
- 集客は SEO / SNS（Instagram・X・Threads 等）を主軸にオーガニックで構築
- 初年度目標: 年商 2,000 万円、営業利益黒字、初期投資は最小限
- ツナカレとの整合性: 現状は部活単位の登録が中心で紹介可能な母集団が限定的
  → 本サービスで **個人単位の登録** を確立し、「頑張る学生を応援する」設計で相互送客する
