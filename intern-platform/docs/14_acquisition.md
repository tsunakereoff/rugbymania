## 1. 価格の最終形（単価は下げない）

ご指摘を反映: 審査・フィルタリング済みの優秀層を売る以上、ゼロワン（8.8万円）と価格で並ぶ必要はない。選択制メニュー（12_gtm-plan §1のA/B）は廃止し、単一プランに戻す。

| 項目 | 価格 |
|---|---|
| インターン採用（稼働開始時） | **15万円**（30日以内離脱50%返金） |
| 新卒転換フィー | **稼働6ヶ月未満で内定承諾: 35万円 / 6〜12ヶ月: 25万円 / 12ヶ月超: 15万円 / 卒業時に自動消滅**。内定辞退は全額返金 |

- 価格の正当化ロジック: 「審査済み・書類選考不要・面談確約・推薦文付き・ドタキャン抑制済み」の選考コスト削減価値で15万円を売る。比較訴求は「新卒紹介85〜130万円・紹介予定派遣60〜140万円に対し、最大合計50万円」
- 転換フィーの前提（事前明示・逓減・卒業時消滅・迂回防止条項）は12_gtm-plan §1のまま
- フォールバック（実地で受注率が想定を大きく割った場合のみ）: 転換フィーを「初期フィー割引との選択制」に戻す。ただし第一の対応は価格ではなく訴求の改善とする

## 2. 募集形態: 「公開ショーウィンドウ × 審査制メンバーシップ」のハイブリッド

「オープンサイトで募集する形か？」への回答: **半分だけオープン**。

| レイヤー | 公開範囲 | 置くもの | 目的 |
|---|---|---|---|
| **公開レイヤー（オープンサイト）** | 誰でも閲覧可 | ①参加企業と求人ページ（**閲覧は公開・応募ボタンはなし**。CTAは「審査にエントリー」のみ） ②審査の説明・合格者の顔ぶれ・実績数 ③記事・診断・ガクチカ言語化ツール | SEO（求人ページはJobPosting構造化データでGoogleしごと検索に露出）・信頼形成・審査エントリーの獲得 |
| **メンバーレイヤー（審査通過者限定）** | クローズド | ①マッチ提示（面談確約）と応募 ②スカウト受信（共通DB） ③実績書・フィードバック ④限定イベント・コミュニティ | USPの提供の場。「求人は見えるのに、会えるのはメンバーだけ」という構造自体が審査エントリーの動機になる |

- 完全クローズ（招待制のみ）はSEO・信頼形成を捨てることになり、完全オープン（誰でも応募）はUSPと審査の意味を壊す。ハイブリッドが唯一両立する
- 実装上は Phase 0 から: 公開LP+求人一覧（応募ボタンなし）+審査エントリーフォーム。メンバー機能はLINE+手動で開始し、Phase 1でアプリ化

## 3. 学生集客アーキテクチャ（「もう少しちゃんと」への回答）

### 3-1. 誰を獲るか — 優秀低学年の4類型と居場所

| 類型 | 特徴 | 居場所（接触チャネル） | 刺さるフック |
|---|---|---|---|
| T1 挑戦系（起業・団体幹部） | 実績あり・情報感度高 | 起業部・TORYUMON・ビジコン・学生団体幹部・X | 面談確約（時間を無駄にしない）・界隈の著名アドバイザー |
| T2 専門系（エンジニア・デザイン・資格） | スキルはあるが企業接点がない | 技育CAMP/JPHACKS・GitHub・専門学校/情報系学部・資格予備校界隈 | 高時給専門求人・実績書（ポートフォリオ化） |
| T3 発信系（SNS・コンテンツ） | 発信力あり・キャリア関心高 | X・note・Instagram・TikTok | 実績書・「審査に通った」というシグナル |
| **T4 未覚醒優等生（最大ボリューム）** | 真面目で優秀だが何をすべきか知らない。ガクチカ不安だけがある | **検索（「大学2年 何かしたい」「ガクチカ ない」）・Instagram・友人の口コミ・大学の履修/時間割アプリ圏** | **ガクチカ言語化ツール・診断・「落ちてもフィードバック」**（低リスクの入口） |
- T1〜T3は一本釣り・界隈ハブ・イベントDMで「点」で獲る（13の設計）。**T4が数の主戦場**で、ここはコンテンツ+広告+紹介の「面」で獲る。T4は自己認識が「優秀」ではないため、「優秀層向け」と訴求すると自分事にならない → 入口は「診断・言語化ツール」の低ハードルコンテンツにし、審査は「やってみたら通った」体験に設計する

### 3-2. 何で獲るか — オファー階段（入口→審査→活性）

```
入口（無料・登録不要〜LINE登録）      審査エントリー           メンバー活性
─────────────────────────────────────────────────────────────
30秒志向診断                    →  「診断結果+あなたなら   →  マッチ提示2〜3件
ガクチカ言語化AIツール              審査に通る可能性◯%」  →  面談確約体験
「面談確約の企業一覧」の閲覧     →  エントリー（15分課題）  →  実績書が貯まり始める
記事・SNSコンテンツ                                          →  招待枠3件付与
```
- 入口コンテンツはすべて「審査エントリーへの導線」を内蔵。特に**ガクチカ言語化AIツール**はT4の最大の痛み（ガクチカ不安）に直撃し、そのまま審査のF2（実績申告）の下書きになる＝入口と審査が接続している
- 落ちた場合もフィードバック+再挑戦パスで関係を維持（LINE内で育成配信 → 次学期に再エントリー）

### 3-3. どう払うか — ユニットエコノミクスと有料広告の格上げ

転換フィー導入後のプール1人あたり期待売上（保守的仮定: 決定率6%/人・決定の20%が転換・転換フィー平均25万円）:

> 0.06 × (15万 + 0.2×25万) = **約12,000円/通過者**

- **許容CAC: 通過者1人あたり4,000円（期待売上の1/3）＝申込1件あたり約2,000円（通過率50%）**
- この水準なら学生向けリード広告（Instagram/TikTok、相場2,000〜5,000円/件）が**採算ラインに乗る**。よって有料広告を「補助」から**制御可能な獲得エンジンの一つ**に格上げする。ただしガードレール付き: ①CPA上限2,000円/申込を超えたクリエイティブは即停止 ②月間広告費は前月売上の20%を上限（売上ゼロの9〜10月は月5万円上限のテスト運用）③広告の着地は求人ではなく入口コンテンツ（診断・言語化ツール）
- オーガニック（紹介・団体・SEO・SNS）は「CACゼロの土台」、広告は「目標未達分を埋める調整弁」という役割分担。**集客が運任せにならないのはこの調整弁があるから**

### 3-4. チャネルポートフォリオ（3層×担当×週次アクション）

| 層 | チャネル | 週次アクション（工数） | 月間申込目標（Q4） |
|---|---|---|---|
| 即効層（0〜3ヶ月から効く） | 一本釣りDM（T1/T2） / 有料広告（T4） | 入賞者・界隈リスト20件DM（1h）/ 広告クリエイティブ2本入替（1h） | 15 / 25 |
| 中期層（3〜6ヶ月） | 招待制リファラル / 学生団体・イベント提携 | 合格者への招待枠リマインド（0.5h）/ 団体・イベント窓口2件（1h） | 30 / 15 |
| 資産層（6ヶ月〜） | SEO（求人ページ+記事）/ SNSオーガニック / 一次データPR | 記事1本+求人ページ整備（3h）/ 投稿バッチ（水曜4hに含む）| 25 / 15 |
| **計** | | 週+2.5h（既存の週次オペに追加） | **月125申込 → 通過60〜65人** |

- 目標を月100→125申込に上積みするのは、広告という調整弁を得たため（オーガニック未達時も申込総量を守れる）
- 計測: チャネル別に 申込→通過→活性（初回応募/スカウト返信）→決定 まで追い、**「プール加入単価」と「決定単価」の2指標**で毎月ポートフォリオを再配分

### 3-5. 集客の前提が崩れたときの順番（プレモータム）

1. 広告CPAが2,000円/申込に乗らない → クリエイティブを「面談確約」訴求から「ガクチカ言語化ツール」訴求へ（コンテンツオファーの方が学生広告は安い）
2. 招待が回らない → 招待インセンティブ追加（招待した側にもフィードバック優先権等の非金銭特典）
3. 申込は来るが通過率が低すぎる（母集団の質） → 入口を診断からポートフォリオ提出型に寄せ、T1/T2比率を上げる
4. すべて低調 → Gate 3（累計10決定・プール300人）の判定に従い縮小/ピボット
