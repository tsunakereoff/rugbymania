# 01. 市場調査 — 日本の大学生・長期インターンシップ市場（2024〜2026年）

作成日: 2026-08-20 / 調査方法: 公開Web情報（マイナビ、リクルート就職みらい研究所、キャリタス（ディスコ）、学情、文科省、経産省、長期インターン専門媒体各社）

> **調査上の制約（重要）**: 数値の一部は検索エンジン経由の要約・二次引用に基づく。**意思決定に使う数値は必ず出典URLの一次資料で再確認すること。**

---

## 1. 市場規模

### 1-1. 母数となる大学生数（文科省「学校基本調査」令和7年度速報）

| 区分 | 人数 | 備考 |
|---|---|---|
| 大学在学者総数 | 約297.2万人 | 過去最多 |
| うち学部学生 | 約264.6万人 | 1学年あたり約65万人前後 |

出典: [文科省 学校基本調査 令和7年度](https://www.mext.go.jp/b_menu/toukei/chousa01/kihon/kekka/k_detail/2025.htm)

### 1-2. インターン全体（短期含む）はほぼ「全員参加」の行事化

| 指標 | 数値 | 出典 |
|---|---|---|
| 26卒 インターン・仕事体験参加率 | **85.3%**、平均参加社数5.2社（過去最高水準） | マイナビ 2025年2月 |
| 26卒 参加経験（キャリタス学生モニター） | 92.7%、平均11.2社 | キャリタス 2025年2月 |
| 26卒 参加プログラムに占める「半日・1日」の割合 | **82.4%**（短期化が進行） | リクルート 就職白書2026 |
| 27卒 5日間以上のインターンシップ参加率 | 27.7% | マイナビ 2025年10月 |

### 1-3. 長期インターン（有給・実務型）参加率は全体の2〜4%にとどまる

| 期間 | 参加率 | 出典（引用元調査） |
|---|---|---|
| 2週間以上 | 4.0% | 就職白書2025 |
| 2カ月以上 | **2.2%** | 就職白書2024 |
| 3カ月以上 | 2.3〜3.0% | 就職白書2023（媒体引用に幅） |

→ 短期参加率85〜90%超に対し、**実務型・長期は約2〜4%。20〜30倍以上の開き**。

**推計（概算）**: 1学年約60〜65万人 × 2〜4% ＝ 1学年あたり約1.5〜2.5万人。複数学年にまたがるため、**同時稼働中の長期インターン生は全国で概ね3〜6万人規模**（一次統計なし、機械的概算）。

### 1-4. 学年別

- 大学1・2年時のインターン参加経験（27・28卒対象）: **30.1%**（24・25卒対象の過年度調査20.7%から約10pt上昇）— マイナビ低学年キャリア意識調査 2025年1月
- 長期インターン限定の学年別参加率統計は**データなし**（媒体では「大学2〜3年開始が多い」との定性傾向のみ）

## 2. トレンド

### 2-1. 25卒からのインターン定義変更（三省合意改正・産学協議会4類型）

- タイプ1（オープン・カンパニー）/ タイプ2（キャリア教育）/ **タイプ3（汎用的能力・専門活用型: 5日以上・半分超が実務。学生情報の採用利用が可＝事実上の採用直結解禁）** / タイプ4（高度専門型）
- 民間の「長期インターン（有給・実務・通年・学年不問）」の多くはこの類型の**枠外**で運用されている点に注意

### 2-2. 採用直結化の進行（就職白書 時系列）

| 指標 | 過去 | 直近 |
|---|---|---|
| 採用目的でインターン等を実施する企業 | 23.2%（17卒） | **62.8%（26卒）** |
| 内定者にインターン等参加者を含む企業 | 72.5%（17卒） | **83.7%（26卒）** |
| 新入社員に占める自社インターン等参加者 | 23.4%（20卒） | **36.3%（26卒）** |

### 2-3. 早期化

- 27卒の約半数が大学2年以前に就活開始（ONE CAREER 2025年3月）
- 27卒の5月時点で夏インターン準備開始 99.2%、エントリー済 65.6%（ONE CAREER 2025年7月）

### 2-4. 企業側の受け入れ動向

- 27卒でインターン・仕事体験「実施・実施予定」の企業 **69.8%**（マイナビ 2025年12月）
- 27卒で採用連携可能な「5日以上」型を「実施する+検討中」**46.7%**（学情 2025年7月）

## 3. 企業側の属性・目的・予算感

- 長期インターン募集は**ベンチャー・スタートアップ中心、半数以上が東京都内**（Renew等）
- 目的: ①新卒採用の母集団形成 ②ミスマッチ防止 ③企業PR ④若手戦力化。インターン参加者への早期選考実施50.4%+選考優遇20.4%＝**約7割が採用選考に接続**（学情 27卒）
- 費用相場:

| 費目 | 相場 |
|---|---|
| 求人サイト掲載料（広告型） | 月額 約3万〜30万円 |
| **成果報酬型（採用1人あたり）** | **文系 約10万円、理系 15〜25万円** |
| インターン生人件費 | 時給1,000〜1,500円中心。週2〜3日で月8万〜13万円/人 |

## 4. 学生側の行動

- 情報源は**就職情報サイトが86.2%**と支配的。ただし就活での SNS 利用は LINE 45.6% / X 36.4% / Instagram 32.7% / YouTube 26.0%、**85.8%が気になる企業名をSNS検索**、SNS経由エントリー経験27.5%（マイナビ・キャリアトラス）
- 長期インターン探索は特化型媒体 + エージェント + SNS直接募集 + 友人・先輩リファラル + キャリアセンターの併用が定石
- 長期インターン内定者の平均応募社数 **4〜5社**、選考合格率 **5〜10%程度**（媒体各社公表）
- 辞退・早期離脱率の信頼できる統計は**データなし**。断片情報では「半年以上継続は約40%」（=半数超が半年未満で離脱の可能性）。求人側は最低3カ月・推奨6カ月以上を要求するのが一般的

## 5. 地域偏在

- 募集企業の**半数以上が東京都内**。大阪・名古屋でも選択肢は限定的
- 参加率が低い主因の一つが地理的要因。対応として**フルリモート長期インターン**が拡大（COMPUS: 全国348件中フルリモート162件、2026年8月閲覧時点）
- 時給の地域差大（東京平均約1,239〜1,345円 vs 地方は最低賃金近傍）

## 6. 新卒採用市場との接続

- 26卒 内定先が「インターン等参加企業」の割合 **50.7%**（キャリタス 2025年10月）
- インターン参加後に企業からフォローを受けた学生は9割強（早期選考案内68.0%）
- 経産省・文科省検討会調査: 長期インターン経験が長い新入社員ほど初職満足度・会社への信頼が高い傾向
- 長期インターン経験者に限定した内定率の大規模統計は**データなし**

## 7. サマリー（市場構造の要点）

1. **二極構造**: 「短期・採用広報型」（参加率85〜92%）と「長期・実務有給型」（参加率2〜4%、推計稼働3〜6万人）は事実上別市場。**長期側は圧倒的に未開拓＝伸びしろ**
2. **規制追い風**: タイプ3解禁で「実務型インターン→採用直結」が公認。企業の採用目的実施率は10年で23%→63%
3. **供給はベンチャー×東京集中**: 成果報酬相場は10〜25万円/人。**当社想定の15万円は相場ど真ん中で妥当**
4. **学生獲得チャネル**: 情報サイト支配だが、SNS検索行動とリファラルが長期インターン特有の穴場
5. **データ空白地帯**: 長期インターン限定の学年別参加率・離脱率・地域別統計・経験者内定率は存在しない → **自社調査を発信すれば一次データホルダーになれる（PR・SEO資産）**
