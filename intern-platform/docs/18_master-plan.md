# Part 1. 事業戦略（確定版）

## 1-1. 一言で

> **ツナカレインターン = 審査制・招待制の「優秀低学年タレントプール」。**
> 学生には「審査1回で、書類選考なしの面談確約・実績書・新卒までつながるキャリア基盤」を無料で。
> 企業には「審査済みの優秀な低学年だけのDB」を完全成果報酬で。

## 1-2. なぜ勝てるか（調査で検証済みの根拠）

1. **市場の空白は実在する**: 大手撤退（キャリアバイト2026/3・JEEK2023）は市場の死ではなく「大手の固定費・機会費用との不一致」。市場天井は年15〜25億円と小さく、これが参入障壁として働く（07）
2. **掘るべき空白は3つ**: ①インターン→新卒転換の収益化（学生1人あたりLTV約10倍。新卒事業を自社に持つ当社だけが内製で完結できる） ②低学年個人DB ③審査制×面談レス。避けるべき空白: 口コミ専業（実質0社=不成立）・掲載課金（無料圏に破壊済み）（07）
3. **学生の痛みが明確**: 選考合格率5〜10%・平均4〜5社応募＝「応募して落ちまくる」体験。当社は審査1回で面談確約に変える（13）
4. **競合不在の交点**: UT-Boardは東大早慶の学歴フィルタ、新卒スカウトは3年生〜。「実力審査×低学年」は空いている（12）
5. **持続優位はツナカレ資産（点火剤）ではなく**、①蓄積型データ資産（審査済みDB・実績書・適性データ） ②損益分岐の低さ（月2決定・AI内製開発） ③新卒2段目の内製、に置く（09）

## 1-3. ターゲット（優秀低学年・4類型）

| 類型 | 獲り方 |
|---|---|
| T1 挑戦系（起業部・団体幹部・ビジコン） | 一本釣りDM・界隈ハブ（TORYUMON等）・招待制 |
| T2 専門系（エンジニア・デザイン・資格） | 技育CAMP/JPHACKS入賞者DM・ポートフォリオ導線 |
| T3 発信系（SNS・note） | X/noteコンテンツ・タイプカードシェア |
| **T4 未覚醒優等生（数の主戦場）** | 診断・ガクチカ言語化ツールの低ハードル入口（「優秀層向け」と訴求しない——自己認識が優秀ではないため） |

体育会はコアから外す（実需は関東高学歴・非レギュラーのみ、部の転送率も低い）。ツナカレ接点で自然に取れる分だけの「おまけ」。

## 1-4. 価格（確定）

| 項目 | 価格 |
|---|---|
| 学生 | 完全無料 |
| インターン採用（稼働開始時） | **15万円**（30日以内離脱で50%返金） |
| 新卒転換フィー | **稼働6ヶ月未満で内定承諾35万 / 6〜12ヶ月25万 / 12ヶ月超15万 / 卒業時自動消滅**。内定辞退は全額返金。掲載契約に事前明示+迂回防止条項（応募から1年以内の直接採用も対象） |

単価は下げない（審査済み優秀層に価格競争は不要）。比較訴求は「新卒紹介85〜130万・紹介予定派遣60〜140万に対し最大合計50万」。転換フィーの類例は紹介予定派遣（年収20〜30%・稼働逓減）に実在（12）。

## 1-5. 数字（誠実なレンジ）

- 初年度の現実レンジ: **決定40〜60件＝売上600〜900万円・営業黒字**（コスト約160万+創業特典値引き）。年商2,000万はストレッチ目標
- **コミットする勝利条件（12ヶ月）**: ①人手なしで月10決定ランレート ②プール800人 ③新卒送客転換5件 ④集客チャネルの白黒
- **ゲート**: Gate1(10月末: 求人20・審査申込50) / Gate2(12月末: 累計5決定) / **Gate3(6ヶ月: 累計10決定・プール300・CAC3,000円未満 → 未達でpivot: DB資産を残しツナカレ送客特化へ)** / Gate4(12ヶ月: 勝利条件判定)
- 市場天井（年15〜25億）があるため、事業評価は**単体PLでなくツナカレ送客LTV込みの全体**で行う

## 1-6. 集客（供給先行・3層+調整弁）

1. **9月は企業が先**: 他媒体掲載企業600〜1,000社への定型アウトリーチ（週50社・「審査済み学生・書類選考なし・面談確約」条件）→ 面談確約求人10〜20件を確保してから学生を集める（無名期の信用は「会える企業のロゴ」で作る）
2. 学生: 1期生20人の一本釣り（実名紹介ページ・NewsPicks Student Picker方式）→ 招待制（合格者に月3枠）→ 学生団体タイアップ（ドットジェイピー最重要・現物ギブ）→ X/note・審査プロセス公開コンテンツ
3. **有料広告は採算の乗る調整弁**: 転換フィー込みのプール1人あたり期待売上約1.2万円 → 許容CAC=申込2,000円。CPA超過クリエイティブ即停止・広告費は前月売上20%上限・着地は診断/言語化ツール
4. 審査ブランド（倍率公開等）は実績が付く9ヶ月目以降の武器。無名期の集客装置にしない
5. SEOは記事でなく**データ資産**（求人構造化データ・一次調査・AIO引用獲得）。検索1位でもCTR9%のAI検索時代を前提に設計

## 2-4. 適性検査（実装済みエンジンの要件）

- **エンジンは1つ**: `@tsunakare/assessment`（純粋関数・テスト66件）。ツナカレ本体（体育会G1）とツナカレインターンで共有
- **出力は完全同一**: Big5・30特性・16タイプ・志向TOP3・適合度計算。**違いは設問文言（athletic/general 14問）とノルム（体育会/一般を別管理）のみ**。データ形も同一＝共通ID接続時に互換
- スコアリング: 逆転→因子平均→パーセンタイル→Kelley縮約（信頼性はパック数連動・パイロット実測で置換）
- マッチング: チャネルA（求める特性×バンドスコア非対称）×チャネルB（志向の個人内センタリング×提供環境）の調和平均→プール内正規化・SEM同順位
- 品質: V1〜V6合議制（2フラグでrecheck・単一指標で弾かない）
- 未較正の間は「検証済み」表記を出さない。インターン側の回答が初回パイロット（分析スクリプト同梱予定）

## 2-5. 非機能・法務

- 稼働中システム（ツナカレ本体・CRM）無変更。別リポ（tsunakare-intern→安定後にtkobaへTransfer）・別DB（Supabase+RLS）・別デプロイ（Vercel）
- テスト: 課金（転換フィー逓減・返金）とスコアリングはテストファースト。E2E3経路。PRごとCI・main直push禁止
- 法務: **職業紹介許可 2026-11-02発行予定**。発行前は媒体型運用（9〜10月=公開サイト・審査・企業開拓のみ、11/2からマッチ提示解禁）。金額・課金条件はコードに埋めず契約スナップショットに保存
- 学生個人情報は応募（マッチ受諾）まで企業非開示。プライバシーポリシーに診断結果の利用目的明記

# Part 3. ツナカレとの接合設計（検討のたたき台）

接合は5層に分けると議論しやすい。各層に「確定済み/提案中/未決」を明記する。

## 3-1. ブランド接合 【確定済み+1論点】

- サブブランド「ツナカレインターン」で確定。学生向けには「部活生専用ではない」を明示
- **論点A: ドメイン構成** — 案1: `intern.tunakare.jp`（サブドメイン・ブランド統一・推奨）/ 案2: 独自ドメイン（独立性）。SEO実務は「関連コンテンツは同一サイト」推奨だが、tunakare.jpのドメイン資産が小さいため差は小さい。**推奨: intern.tunakare.jp**

## 3-2. データ・ID接合 【方針確定・実装順未定】

```
学生の一生モノキャリアプロフィール（共通ID）
  部活単位データ(ツナカレ既存) ──┐
  適性検査結果(本体G1で受験) ────┼── 共通スキーマ(personality_profiles互換)
  インターン実績書・行動信頼 ────┤    ノルムだけ体育会/一般で別管理
  審査結果・志向性 ──────────────┘
```

- インターン側で作る学生ID・プロフィール・assessmentスキーマは実装仕様書準拠＝**本体が適性検査を実装したときそのまま繋がる形**
- 部活単位→個人IDの転換: 部員が個人アカウントを作った時点で club_units に紐付け（ツナカレの「個人単位登録の受け皿」がインターン側で先に完成する）
- **論点B: 共通ID の物理設計** — 本体の認証実体（ミラー到着待ち）を見て、①同一Supabase/DBに寄せる ②ID連携（crosswalkテーブル）のどちらかを決定。それまでインターンは独立Authで構築（後から統合可能なスキーマ）

## 3-4. 収益接合 【ラダー確定・2段目が最大の未決】

**PieceTimes 学生キャリア料金ラダー（確定案）**

| 段階 | 商品 | 価格 | 商流 |
|---|---|---|---|
| 1 | 部活・団体の接点構築 | 接点単価1〜2万円 | ツナカレ |
| 2 | 長期インターン採用 | 15万円（30日返金） | ツナカレインターン |

| 4 | 通常の新卒紹介・採用支援 | ツナカレ既存料金 | ツナカレ |

- カニバリ防止: すべての遷移に価格と商流を事前明文化。インターン企業が部活接点を望んだらツナカレへ社内送客（クロスセル）
- **論点E（最大の未決）: 段階4の実体** — 現行ツナカレは接点課金モデル。**成果報酬型の新卒紹介商品は実在するか？** 無ければ「インターン経験者→新卒側」の受け皿商品（例: 内定承諾時の成果報酬、またはスカウト年間利用料）を設計する必要がある。二段ロケットのLTV（学生1人あたり約10倍）はここに懸かっている
- 論点F: 段階1との相互送客 — インターン側の学生が部活所属だった場合のツナカレ接点への送客価値の値付け（当面は無償の相互送客でよいか）
