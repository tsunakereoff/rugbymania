# 11. 修正モデル — 面談レス設計・ターゲット転換・カニバリ整理

作成日: 2026-08-20 / 第3回フィードバック反映:

## 1. 面談レスは成り立つか → 成り立つ。ただし「面談の機能」を分解してプロダクトに移植する

面談が担っていた機能は3つ。それぞれ人力なしで代替する:

| 面談の機能 | 面談レスでの代替 | 実装 |
|---|---|---|
| ① 志向のすり合わせ（合う求人だけ提示） | **非同期の構造化ヒアリング** | LINE上で5〜10分のフォーム+音声入力可の設問（志向・稼働・やりたくないこと）→ AIが「志向サマリー」を生成し本人が確認・修正 → 求人は全件一覧ではなく**マッチ理由付きで2〜5件だけ提示** |
| ② 企業への推薦（面談実施率を上げる） | **AI推薦文の自動生成** | 志向サマリー+プロフィールから応募ごとに推薦文を自動生成し、本人確認後に企業へ送付。企業には「素の応募」が届かない設計 |
| ③ ドタキャン抑制（コミットの担保） | **剥奪可能な会員資格** | 審査制プール（§2）だから効く: 応募確定前の意思確認ステップ（日程を自分で選ぶ）+ リマインド + **無断欠席でプール資格停止**。「選ばれた場を失う」ペナルティが人力の代わりに規律を作る |

- 決定率の想定: 人力面談 10% ＞ **非同期AI審査 5〜7%** ＞ 素通し媒体型 2〜3%。面談レスで失うのは3〜4ポイントだが、**founderの面談キャパ（週8件）という最大のスケール制約が消える**ため、機械としてはむしろ強い
- 保険: 決定率が5%を割った場合のみ「決定確度上位の学生に限定したスポット面談」を一時投入するオプションを残す（恒常運用にはしない）
- 11/2の職業紹介許可は面談レスでも活きる: 推薦・選別・条件調整という「紹介行為」をシステムが行うため、許可を持って堂々と設計できる

## 2. ターゲット転換 — 「優秀な一般学生の低学年」は勝ち筋か → **勝ち筋。体育会チャネルより筋が良い**

### 体育会チャネルの棚卸し（ご指摘の反映）
実需は「関東・高学歴・体育会で試合に出ていない時間のある学生」というマイクロセグメントに限られ、部の転送率も見込めない → **体育会・引退層はコアチャネルから外す**（ツナカレとの个別接点で自然に取れる分だけ拾う「おまけ」に格下げ。10_tactics.md のチャネルAは本書で置き換え）。

### なぜ「優秀な低学年」の方が筋が良いか（3つの理由）
1. **企業需要が最も強い交点**: ベンチャーが長期インターンで本当に欲しいのはまさに「優秀で時間のある低学年」（早く来て長く働き、新卒候補にもなる）。成果報酬15万円は企業から見て圧倒的に安い
2. **競合の空白が実在する**: UT-Boardは東大・早慶の学歴フィルタ、OfferBox等の新卒スカウトは3年生以降、外資就活も3年〜が主戦場。**「学歴不問の実力審査×低学年」のポジションは空いている**（02/07の調査と整合）
3. **面談レス・セルフサーブと相性が最良**: 優秀層は自走できる（自分で書ける・動ける）ため、人力サポートなしで質が保てる。「アルバイト感覚」問題も優秀層では最小

### 勝ち筋の再定義

> **「審査制・招待制の優秀低学年タレントプール」**
> 学生には「審査を通ると、厳選求人・スカウト・同世代の優秀層コミュニティにアクセスできる」選抜の価値を無料で提供し、
> 企業には「審査済みの優秀な低学年だけのDB」を成果報酬で売る。

- **審査の実装（「優秀」を言葉でなく仕組みにする）**: 学歴は参考情報に留め、①実績申告（活動・作品・成果） ②小課題（15分のケース/ライティング/コード等、志向別）③非同期ヒアリングの3点をAI一次評価+抜き打ち人力監査で判定。通過率は5割前後を想定し、**落とす審査であることが企業への品質保証とブランド（選ばれた感）の源泉**
- **獲得チャネル（優秀低学年はどこにいるか）**:
  - 学生団体・ビジコン・ハッカソン・起業サークルとの提携/協賛（ツナカレの学生団体接点を転用。体育会網より本ターゲットに適合）
  - **招待制リファラル**: 審査通過者に招待枠2〜3（優秀層は互いにつながっている。招待制自体がブランドになる）
  - X/note の質の高いキャリアコンテンツ+一次データ（優秀層の情報行動に合致。AI検索引用も狙う）
  - 審査落ちも無駄にしない: 再挑戦導線+育成コンテンツ（母集団の将来在庫）
- **リスクと正直な留保**: ①優秀低学年の絶対数は少なく、獲得競争は存在する（ただし当社は年50〜70決定で成立する規模設計なので、大きな母集団は不要） ②「審査」の納得感を欠くと炎上リスク → 基準の透明化と再挑戦制度で担保 ③彼らは放っておいてもWantedlyで動ける層 → 当社を使う理由は「審査済みだから来るスカウト・厳選求人・コミュニティ」の3点セットで作る

## 3. カニバリ（機会損失）の整理 — 「全ての遷移に値段をつける」

懸念: ①紹介したインターン生がそのまま新卒入社 → 新卒紹介（100〜200万円）の機会損失? ②インターン企業がツナカレ経由で部活とつながる → ツナカレ商流の混乱?

**結論: 料金ラダーを1枚に統一し、学生・企業のすべての遷移に価格と商流を明文化すれば、機会損失は消えてアップセル経路に変わる。**

### PieceTimes 学生キャリア料金ラダー（案）

| 段階 | 商品 | 価格 | 商流 |
|---|---|---|---|
| 1 | 部活・学生団体との接点構築（ツナカレ） | 接点単価 1〜2万円 | ツナカレ |
| 2 | 長期インターン採用 | 成果報酬 15万円（30日以内離脱50%返金） | 本サービス |
| 3 | **インターン生の新卒転換**（当社経由のインターン生をそのまま新卒採用） | **転換フィー 35万円（仮・要決定）** を利用規約・掲載契約に明記 | 本サービス（新設） |
| 4 | 通常の新卒紹介・採用支援 | 既存ツナカレ料金 | ツナカレ |

### 遷移ごとの整理

| 遷移 | 一見の機会損失 | 実際の整理 |
|---|---|---|
| インターン生→そのまま新卒入社 | 新卒紹介100〜200万円を取り损ねる | **機会損失ではない**: ①その学生と企業は当社経由でなければ出会っていない（失った売上ではなく生んだ接点） ②通常の新卒紹介在庫とは別物 ③転換フィー35万円で回収する——企業から見れば市場価格（85〜130万円）の1/3以下で、しかも実働済み＝ミスマッチリスク最小の採用なので喜んで払える価格。ジョブコミットは転換0円を企業誘引に使ったが、当社は誘引を「審査済みDB」で作れるためフィーを取れる。**契約に入れ忘れると本当にただの機会損失になるため、Phase 0の掲載規約に必ず盛り込む**（転換フィーの適用範囲: 稼働開始から卒業までの入社、等の細部は法務レビューで確定） |
| インターン企業が「部活・学生団体とつながりたい」と言い出す | ツナカレの接点課金を bypass される | **クロスセル送客としてルール化**: 本サービスは接点構築を扱わず、希望企業はツナカレ料金表で対応（社内送客。逆にツナカレにとって新規リード獲得チャネルになる）。企業向け料金表を1枚にして両商品を並記すれば bypass の余地自体がなくなる |
| ツナカレ既存企業がインターン掲載 | 二重課金感の懸念 | 商品が別（接点=部活との関係構築 / インターン=採用成果）であることを統一料金表で明示。むしろ段階1→2のアップセル |
| 学生: インターンプール→ツナカレ新卒送客 | — | 共通ID+本人同意で設計済み（05）。プール学生は「実務経験+審査済み」の状態で新卒商材になるため、段階4の在庫の質を上げる |

**原則: 「どちらのサービスの売上か」で迷う取引が発生した時点で設計ミス。迷いを消すのは営業ルールではなく、事前に公開された1枚の料金表と契約条項。**

## 4. 残る確認事項

1. **転換フィーの水準**: 35万円（仮）で規約に入れてよいか（相場: ジョブコミット0円〜新卒紹介85万円の間。30〜50万円が合理レンジ）
2. **「審査」の基準への考え方**: 学歴をどの程度加味するか（企業需要は高学歴に寄る現実 vs 学歴不問の実力主義というポジショニング。推奨は「学歴は表示するが審査基準にはしない」）
3. 10_tactics.md のゲート指標の差し替え: Gate 1を「求人20件・審査申込50人・通過30人」、Gate 3を「累計10決定・プール300人・CAC3,000円未満」に更新してよいか
