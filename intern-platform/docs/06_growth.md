# 06. グロース戦略（SEO / SNS / ツナカレ連携）と KPI 設計

ステータス: **ドラフト（レビュー待ち）** / 最終更新: 2026-08-20

前提: 営業人員ゼロ・広告費最小限で「自走する」集客構造をつくる。
チャネルの根拠となる学生の情報行動は [03_insights.md](03_insights.md) を参照。

---

## 1. 集客の基本構造

```
[認知]                [比較検討]              [登録/応募]           [再生産]
SNS(Instagram/TikTok/  SEO記事・口コミ・     LINE登録→志向診断→   稼働学生の口コミ・
X/Threads)・友人紹介 →  求人詳細(構造化)   →  応募            →   体験談が新規コンテンツに
                                                                （コンテンツの自己増殖）
```

コアの設計思想: **「稼働した学生の体験談・口コミ」がSEOコンテンツとSNSネタを自動供給する**フライホイールを作る。人手でコンテンツを作り続けるのではなく、プロダクトの仕組み（稼働1ヶ月後・終了時の投稿依頼）がコンテンツを生む。

## 2. SEO 戦略

ラグビーマニアで確立した静的サイト生成・構造化データ・sitemap運用を転用する。

### キーワード戦略（優先順）
| クラスタ | 例 | 狙い |
|---|---|---|
| ノウハウ系（Phase 0 から仕込み） | 「長期インターン とは」「長期インターン いつから」「長期インターン バイト 違い」「長期インターン 面接」 | 検討初期の学生を大量に獲得。競合も強いがロングテールで面を取る |
| 両立・属性系（差別化の主戦場） | 「長期インターン 部活 両立」「体育会 インターン」「長期インターン 週2」「長期インターン リモート 地方」 | ツナカレ層と重なる独自クラスタ。競合が薄く、当社が最も書ける領域 |
| 職種・業界系 | 「営業 インターン 内容」「マーケティング 長期インターン」 | 求人一覧ページ（プログラマティックSEO）と接続 |
| 口コミ・体験談系 | 「(企業名) インターン 評判」「長期インターン 体験談」 | Phase 2 以降、口コミ蓄積とともに最強の資産になる |
| 企業側 | 「長期インターン 採用 方法」「インターン 求人 掲載 無料」「インターン 採用 費用 相場」 | 企業のインバウンド獲得（営業ゼロの生命線） |

- 求人詳細は 1求人1URL・JobPosting構造化データで Google しごと検索にも露出
- ドメイン戦略（新規独自ドメイン）は立ち上げ時に決定（未決事項）

## 3. SNS 戦略

| チャネル | 役割 | コンテンツ方針 | 頻度目安 |
|---|---|---|---|
| **Instagram（リール中心）** | 認知の主戦場（大学1-2年に最も届く） | 「インターン生の1日」「時給いくら?」「面接で聞かれたこと」等のリアル系ショート動画・カルーセル。稼働学生の出演協力（謝礼 or 特典） | 週3-4 |
| **TikTok** | Instagramリールの二次配信 | 同素材の転用 | 週3-4 |
| **X** | 就活文脈・拡散 | 体験談スレッド、調査データの発信（一次データ=引用されやすい）、企業の中の人との絡み | 毎日 |
| **Threads** | Xの二次配信 + 就活垢コミュニティ | 同素材転用 + 学生の悩みへのリプライ運用 | 週3-4 |
| **LINE公式** | 登録後の継続接点（CRM） | 新着求人・診断・応募リマインド。SNSフォロワー→LINE登録→応募の階段設計 | 週1配信 |

- 運用は素材テンプレート化 + 予約投稿で週半日以内の工数に収める
- 独自の一次コンテンツ源: ①稼働学生の体験談 ②自社調査（登録学生アンケート→「長期インターン実態調査」としてプレスリリース化→被リンク獲得。**長期インターンの離脱率・参加実態は公的統計が存在しない空白領域**のため、一次データホルダーになれる）
- **「長期インターン専門」の大型インフルエンサーは現在不在**（就活系はしゅんダイアリー等が存在するが長期インターン特化はいない）→ 発信の空白を先取りするポジション。就活生の63%が企業SNSをチェックし、動画に求めるのは「かっこよさ」より「身近さ・リアルさ」（03_insights.md §5）

## 4. 学生コミュニティ・ツナカレ連携

1. **部活・学生団体ルート**: ツナカレの既存接点（部活単位）に「引退後・オフシーズンの長期インターン」として案内。部活単位→**個人アカウント登録**への転換導線を設計（本サービスのアカウントがツナカレ個人登録の受け皿になる）
2. **友人紹介**: 稼働中インターン生からの紹介インセンティブ（Amazonギフト等・軽量に）
3. **新卒への接続**: 3年秋の引退タイミングで、インターン経験を持った状態でツナカレ新卒紹介へ送客（学生には「ガクチカ+実務経験」という武装、自社には高単価マネタイズ）

## 5. 企業獲得（営業ゼロの設計）

1. **初期20〜30求人**: ツナカレ既存取引企業へメール・既存商談内で案内（新規営業ではなくクロスセル）
2. **インバウンド**: 企業向けSEO（§2）+ 「掲載無料・完全成果報酬」LP + 事例コンテンツ
3. **セルフサーブ掲載**: 申込→審査→公開まで人が会わずに完結（05_requirements.md F1-5）
4. 成果が出た企業の事例記事→それ自体が企業向けSEOコンテンツになる循環

## 6. KPI ツリー

```
年商2,000万円 = 決定数134 × 15万円
決定数 = 応募数 × 応募→決定率(8%)
応募数 = アクティブ登録学生 × 月間応募率(25%)
登録学生 = 訪問数 × 登録率(4%)
訪問数 = SEO流入 + SNS流入 + 直接/紹介
（供給側）決定数 ≤ 掲載求人数 × 求人あたり月間決定(1.0)
```

### 週次モニタリング指標
| 領域 | KPI | Q4目標水準 |
|---|---|---|
| 集客 | セッション数 / SEO流入比率 / SNSフォロワー | 31,000/月 / 50%+ / IG 1万 |
| 登録 | 学生登録数（累計/週次新規）/ LINE友だち数 | 累計5,000 |
| マッチング | 応募数 / 応募→面談率 / 面談→決定率 | 310/月 |
| 供給 | 掲載求人数 / 新規掲載企業数（うちインバウンド比率） | 100件+ |
| 品質（ミスマッチ指標） | **30日継続率 / 90日継続率** / 返金発生率 / 口コミ投稿率 | 90% / 75% / <5% |
| 収益 | 決定数 / 売上 / 請求回収率 | 25/月 |

> 品質KPI（継続率）を売上KPIと同格で追うのがこのサービスのアイデンティティ。「決定数は伸びるが30日で辞める」状態はコンセプト崩壊とみなし、求人フォーマット・診断の改善を優先する。
