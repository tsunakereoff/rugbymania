# 02. 競合調査 — 長期インターン関連サービス（2026年8月時点）

調査日: 2026-08-20 / 調査手法: 公開Web情報（各社公式・プレスリリース・比較サイト・業界メディア）
注: 「事実（出典付き）」と「推測・分析（明記）」を区別。料金非公開の企業が多く、比較サイト経由の情報は時点が古い可能性あり。

---

## 1. エグゼクティブサマリー

- 課金モデルは**成果報酬型が主流**。相場は**1採用あたり文系 約10万円、理系 15〜25万円**（キャリアバイトBiz / digireka）。新卒紹介の相場（固定85〜130万円/名）の**1/5〜1/10**
- 市場構造が2023〜2026年に激変: **JEEK（Techouse）は2023年頃終了**、**キャリアバイト（エン・ジャパン）は2026年3月23日サービス終了を発表**。大手撤退と新興乱立（Renew、ココシロ、Voil、myturn 2025年5月β等）が同時進行
- 大手2媒体の撤退で**純粋な掲載課金型の長期インターン専門媒体はほぼ消滅**。新興勢の共通モデルは「掲載無料+成果報酬」+「アドバイザー面談による送客（媒体×紹介ハイブリッド）」
- 勝ち筋は「SEO+無料面談で学生を囲い込み、成果報酬で薄く収益化し、新卒接続で回収する」モデルに収斂しつつある

## 3. 料金相場の整理

| 領域 | 相場 |
|---|---|
| **長期インターン採用 成果報酬** | **文系 約10万円、理系 15〜25万円**（→ 当社想定15万円は相場ど真ん中） |
| 長期インターン 掲載課金 | 月3万〜30万円（キャリアバイトは月3.8万円〜だった） |
| 新卒スカウト成功報酬 | 35〜45万円/名 |
| **新卒人材紹介** | **固定85〜130万円/名**（年収連動なら想定年収の20〜25%） |

**含意**: インターン1名（10〜25万円）と新卒紹介1名（85〜130万円）の**約5〜10倍の単価差**を利用した「低学年でインターン紹介→3年次に新卒接続で回収」の二段ロケットは、ジョブコミット（転換0円で企業誘引）以外に本格商品化したプレイヤーが見当たらない。

## 5. 市場の空白（分析）

1. **純粋掲載課金・低額サブスクの空白**: キャリアバイト撤退（2026年3月）で月3.8万円・成果報酬なしの選択肢が消滅。常時複数名採用する企業の「定額で採り放題」需要が浮く
2. **エンジニア・理系特化媒体の不在**: JEEK亡き後空白。理系は成果報酬15〜25万円と単価も高い
3. **口コミデータ資産がほぼ独占前**: Voil一社のみ・掲載250社。「OpenWorkの長期インターン版」ポジションは未確立。口コミは後発が模倣しにくいストック資産
4. **「インターン→新卒転換」の収益化モデルの空白**: 転換時に30〜50万円（新卒紹介より大幅に安い中間価格）を取るモデルは企業にも合理的で空白
5. **地方・リモートの供給不足**: 求人は首都圏極端偏在。地方対応はCOMPUSのみ。自治体助成（東京都: 受入企業に1日1名8,000円等）との連携余地
6. **低学年スカウトDBの空白**: 大学1・2年生のプロフィールDBに長期インターンスカウトを打てる専業は不在。新卒スカウト（35〜45万円）転用で高LTV

> **当社への示唆**: 上記のうち (3)口コミ資産 ×(4)新卒転換フィー ×(6)低学年個人DB は、ツナカレ（新卒紹介）保有・営業ゼロ方針・ミスマッチ解消コンセプトと整合する組み合わせ。詳細は 04_strategy.md に反映。
