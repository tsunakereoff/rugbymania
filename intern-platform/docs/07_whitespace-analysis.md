# 07. 市場の空白の性質見極め — 「入り込めていない」のか「おいしくないから」なのか

作成日: 2026-08-20 / 目的: 02_competitors.md で特定した「市場の空白」について、(a) 市場としておいしくないから誰もやらないのか、(b) 競合がまだ入り込めていないだけなのか、を撤退事例の深掘りから判定する。

---

## 1. 結論サマリー

**市場の絶対規模は構造的に小さい（推計 年15〜25億円）が、それは「大手が来られない」という参入障壁として働いており、低コスト事業者のユニットエコノミクスは成立する。** 撤退した大手（エン・ジャパン、Techouse）はいずれも「市場の消滅」ではなく「社内のより大きな機会への資源集中」で撤退を説明でき、実際に需要側（求人在庫・学生登録）は縮小していない。ただし空白ごとに性質が異なるため、個別判定（§5）に従って「埋める空白」と「埋めない空白」を選別する。

| 空白 | 判定 | 当社の行動 |
|---|---|---|
| インターン→新卒転換の収益化 | **(b) おいしいのに掘られていない** | ◎ 主戦場にする（ツナカレ二段ロケット） |
| 低学年個人DB | **(b) 同上に内包** | ◎ 個人単位登録で確立する |
| 体育会系×低稼働求人 | **(b) 競合が構造上拾えない** | ◎ 重点セグメント（要検証） |
| 口コミ専業 | **(a) 単体では成立しない** | △ 付帯機能に格下げ（設計修正済み） |
| 掲載課金・低額サブスク | **(a) 無料圏に価格破壊済み** | × 狙わない（成果報酬方針と整合） |
| エンジニア・理系特化 | 中間 | △ 初年度は狙わず、職種カテゴリの一つに留める |
| 地方×リモート | 中間 | △ リモート求人カテゴリとして自然に取り込む |

## 2. キャリアバイト（エン・ジャパン）はなぜ終了したか

### 事実
- 2026年3月23日サービス終了。**終了理由の公式説明はなく、プレスリリースも打たれていない**。告知は engage への誘導のみ
- **IR資料にキャリアバイトは一度も登場しない**（FY2026.3期2Q決算説明資料全50ページに「キャリアバイト」「インターン」の出現ゼロ件）
- 同時期のエンは激動: 純利益▲65.7%の業績急落 → 「構造改革」（広告宣伝費・人件費を2年で約30%削減、不採算事業の整理）→ **2025年12月に engage 事業をカカクコムへ売却**（85.1%を44.5億円）→ 2026年3月キャリアバイト終了 → 4月に合弁「株式会社エンゲージ」始動
- 規模の推計: 掲載課金 月3.8万円 × 推定常時掲載300〜500社 = **年商1.4〜2.3億円程度**。エン単体売上（約440億円）の0.5%未満
- 同社は2014年にも新卒ナビ「[en]学生の就職情報」を終了しており、「学生メディアの静かな撤退+他サービスへの送客」は同社の定石

### 考察（なぜ大手が月3.8万円モデルを維持できなかったか）
1. **絶対額が小さすぎてPLに乗らない**: 年商2億円ではIRで語る価値がなく、専任営業・CS・開発を維持すれば利益ゼロ近傍
2. **ARPUの天井が低く上げる手段がない**: 長期インターン採用は1社年数名・単価10万円前後。中途のような高単価成果報酬に引き上げる余地がない
3. **社内共食い**: 全社資源を無料掲載の engage に集中 → 月3.8万円のインターン特化媒体の存在意義が社内的にも消えた
4. **営業コスト構造の不一致**: 大手の営業人件費（推定700万〜1,000万円/人年）では年45万円の顧客を数十社担当しても採算に届かない
5. **トリガーは engage 売却**: カーブアウト前の「店じまい」として、対象外の周辺学生メディアを整理し、顧客・学生を売却対象の engage に送り込んだと解釈するのが最も整合的

**含意**: キャリアバイトの終了は「長期インターン市場の死」ではなく「**大手の固定費構造・機会費用に合わない市場である**」ことの証明。むしろ月3.8万円を払っていた掲載企業と上位校比率6割・会員14万人分のトラフィックが行き場を失う、**数年に一度の参入タイミング**（受け皿の engage はインターン特化の検索体験・審査・学生向けコンテンツを提供しない）。

## 3. JEEK（Techouse）・Traimmu の撤退/被買収から分かること

- **JEEK**（媒体×紹介ハイブリッドの先駆、登録7,000人・64%が早慶以上）は2023年終了。ただし Techouse は同型モデルの「ジョブハウス工場」（ブルーカラー・高単価紹介）は残し、**インターンだけを畳んだ**。フルサポート型の学生支援は新卒紹介（80〜150万円/件）なら成立するが、インターン紹介（〜10万円/件）では原価割れしやすい。折しも主力SaaS（クラウドハウス）がトヨタ級に刺さり始めており、「儲からないからやめた」より「**もっと儲かるものが社内にできたのでやめた**」＝機会費用の敗北
- **Infraインターン運営元 Traimmu** は独立成長できず、新卒採用コンサルの Legaseed に吸収合併された。**媒体単体ではなく「新卒高単価事業の集客装置」として買われた**構図

## 4. 口コミ専業はなぜ1社しかない（実は0社な）のか

### 前提の訂正
「口コミ専業1社（Voil）」という前提自体が崩れている:
- Voil運営の Flamers は**リリースからわずか数ヶ月（2020年11月）で有料職業紹介免許を取得しエージェント型へ移行**。現在のVoilの自己定義は「長期インターン専門のキャリアエージェント」で、口コミは付帯機能
- 公表口コミ件数は338件→500件超の水準で頭打ちとみられ、以後「口コミ○件突破」型の発信なし
- 会社としての主力事業は恋愛メタバース「Memotia」に移っており、2022年のシード調達1億円もメタバース事業のため
- → **実態は「専業0社」。当事者が最も早く口コミ単体モデルに見切りをつけた**

### 構造的な理由（新卒・転職口コミとの比較）
| 成立条件 | 新卒・転職 | 長期インターン |
|---|---|---|
| 書き手母数 | 就活生 年40万人超（体験記19万件が成立） | **年1.2〜2.4万人（約1/20）**。1〜2社しか経験せず give-to-get の循環も回らない |
| 閲覧需要 | 「(企業名) 評判」の指名検索が大量 | 受け入れ企業は無名ベンチャー中心・1社数人 → 企業名単位の検索需要が極小 |
| 収益化 | 口コミ自体では誰も稼いでいない（OpenWorkすら収益の7割は送客）。裏に新卒・中途の採用予算がある | 送客先の成果報酬が1桁小さく、**口コミDBの維持コスト（収集・審査・法務）を賄えない** |
| リスク | 削除依頼・開示請求対応が常態化（専門業者が存在） | インターン生数人の会社では**書き手がほぼ特定される** → 本音率低下・企業反発・法務コストの三重苦 |

**判定: (a) 市場が小さすぎる ×「口コミは付帯機能としてのみ成立」の複合。**「先行者がまだ掘れていないだけ」は、5年間で参入ゼロ+当事者のピボットという事実と矛盾する。

**当社への適用（設計修正済み）**: 口コミは収益源でもSEOの主資産でもなく「①学生集客のフック ②信頼形成 ③マッチング精度向上の材料」として求人マッチングの付帯機能に位置づける。生口コミは登録学生限定のクローズド閲覧、公開SEOは編集型体験談記事が担う（05_requirements.md F2-2 / 06_growth.md 反映済み）。将来、採用直結インターンの制度化で参加率が10%台に乗る構造変化が起これば独立採算性を再検討。

## 5. 空白ごとの性質判定（詳細）

1. **インターン→新卒転換の収益化 = 掘られていない空白（最重要）**
   撤退分析の裏返しがそのまま答えになる: インターン紹介単体は1件10万円で誰がやっても薄いが、**同じ学生を新卒紹介（80〜150万円）に流せば学生1人あたりLTVが約10倍**になる。JEEKはこの発想の先駆だったが低単価側に工数をかけすぎ+社内の機会費用で放棄。Traimmuは装置としてLegaseedに買われた。**新卒紹介事業（ツナカレ）を自社内に持つ当社は、この構造を外部売却ではなく内製で完結できる数少ないプレイヤー**
2. **低学年個人DB = 同上に内包**: 新卒スカウト大手は3年生以降が主戦場。1〜2年生の個人DBは「将来の新卒紹介の仕込み在庫」としてのみ経済合理性があり、新卒事業を持たない媒体には作るインセンティブがない → 当社には合理性がある
3. **体育会系×低稼働求人 = 競合が構造上拾えない空白（要検証）**: 媒体は求人側の稼働条件（週3〜）を変えられない。企業と関係を持ち「週1〜2・オフシーズン設計」の求人を作らせることができるのは、体育会コミュニティと企業の両方に接点を持つプレイヤーのみ。ただし「企業が低稼働求人を本当に出すか」は未検証のため、Phase 0 で企業ヒアリングにより検証する
4. **掲載課金・低額サブスク = おいしくない**: engage・Wantedly の無料/低額圏に価格破壊済み。キャリアバイト顧客の「浮いた需要」は取りにいくが、課金は成果報酬で受ける（既定方針と整合）
5. **理系・エンジニア特化 = 中間**: 単価は高い（15〜25万円）が母数が小さく、JEEKの前例もある。初年度は職種カテゴリの一つに留め、特化はしない
6. **地方×リモート = 中間**: 伸びしろはあるが単価がさらに低い。リモート可フィルタとして自然に取り込むに留める（COMPUSと正面衝突しない）

## 6. 市場規模の上限と当社目標の整合

- 市場売上の上限推計: 掲載課金 約5億円 + 成果報酬 約10〜15億円 = **年15〜25億円**（強気でも30億円未満。中途求人広告市場の1%未満）
- プレイヤー10社前後で分け合うため、**シェアトップでも年商数億円、2番手以下は数千万〜1億円台が天井**
- → 当社の初年度目標 年商2,000万円は市場の約1%で、天井論とは矛盾しない。**ただし本事業単体でのスケール上限（数億円）を認識し、事業評価は「ツナカレ新卒紹介への送客LTVを含めた全体」で行う**（04_strategy.md の方針を裏付け）

## 7. リスク（撤退分析からの教訓）

1. **SEO一本足の危険**: 学生集客の主戦場はSEOからTikTok/Instagram/大学コミュニティへ移行しつつある → SNS・コミュニティ導線を最初から並走させる（06_growth.md の設計どおり）
2. **制度変更リスク**: 三省合意改正の運用変化・職業紹介規制は継続ウォッチ
3. **単体Exitの現実解は Traimmu 型**（新卒事業会社への売却）だが、当社は自社内に「買い手」（ツナカレ）を持つため、この点はむしろ構造的優位
