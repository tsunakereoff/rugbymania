## 1. 解くべき課題（Problem Statement)

新卒採用は「複数社を長期間かけて比較し、自己分析・業界分析を経て選考を勝ち抜く」プロセスのため、一定の精度でマッチングが成立する。一方、長期インターンは短期集中で決まるため、学生の判断基準が

- **知っている企業かどうか**（知名度バイアス）
- **求人が面白そうか**（好奇心バイアス）

に偏り、アルバイト応募と同じ感覚で意思決定される。企業側は**将来の新卒採用・戦力化**を期待しているため、期待値ギャップ→早期離脱・採用不成立という本質的ミスマッチが構造的に発生している。

**既存プレイヤー（求人媒体・紹介・口コミ）はいずれも「応募の量」を最適化しており、「応募の質（期待値の一致）」を設計しているサービスがない。ここが空白。**

調査による仮説検証の結果（詳細は 03_insights.md）:
- 仮説1（アルバイト感覚）は部分的に支持: 実像は「バイトの上位互換」+「就活の道具（ガクチカ・選考優遇）」の2動機。いずれも企業期待とズレる
- 仮説2（企業は採用入口として真剣）は強く支持: 採用目的実施は10年で23%→63%。ただし「安価な労働力」目的の企業も混在し、市場の信頼を毀損している（→ 掲載審査が差別化になる）
- 仮説3（ミスマッチ）は支持: ただし離脱率の公的統計は不在＝自社調査で一次データホルダーになれる
- Voilの口コミ統計分析: 満足度を決めるのは業務内容や研修ではなく**「居心地・フィット感」「質問への向き合い方」＝求人票に書けない情報** → 現行の求人フォーマット自体がミスマッチを再生産している

## 2. 3C 分析

### Customer（市場・顧客）
- **学生**: 短期インターンは参加率85〜92%で「全員参加の行事」化した一方、**長期（有給・実務型）の参加率は2〜4%**（同時稼働 推計3〜6万人）。採用直結解禁・就活早期化（1・2年時参加経験30.1%）が追い風で、「興味はあるが動けていない」層が最大のポテンシャル
- **企業**: ベンチャー〜中堅・東京中心。目的は (a) 新卒採用の入口（採用目的実施は10年で23%→63%、参加者の約7割が選考接続） (b) 若手戦力の確保。**成果報酬相場は文系約10万円・理系15〜25万円/名**で、新卒紹介（100〜150万円/名）の約1/10。専任担当がおらず、営業を受けて検討する体力もない → セルフサーブ・成果報酬と相性が良い
- ※数値の根拠・詳細は 01/02/03 の調査ドキュメントに整理

### Competitor（競合）
- 市場構造が激変中: **JEEK（2023年頃）とキャリアバイト（2026年3月）の大手2媒体が撤退**。純粋な掲載課金型はほぼ消滅し、新興勢（Renew・ココシロ・Voil等）は「掲載無料+成果報酬+アドバイザー面談送客」のハイブリッドに収斂
- **求人媒体型**: 応募量は取れるが求人票の情報が薄く、ミスマッチは放置
- **紹介型**: 面談すり合わせで精度は上がるが、単価10〜25万円に対し人件費が重く、スケールしない
- **口コミ型**: 長期インターン口コミ専業は実質 Voil 一社（掲載250社）で独占前の空白。ただし収益化はエージェント併設に依存
- **新卒スカウト型**（OfferBox 38〜45万円/名等）: 3年生以降が主戦場。低学年の長期インターンDBは専業不在
- ジョブコミットインターン（HRteam）が「インターン紹介10〜20万円+新卒転換0円」で新卒クロスセル前提モデルを実践 → 当社の「インターン→ツナカレ新卒紹介」二段ロケットの先行類例
- 詳細比較は 02_competitors.md

### Company（自社: PieceTimes）
- **資産**: ①ツナカレの企業ネットワーク（新卒紹介の既存取引先→インターン求人の初期開拓に転用可能） ②部活生・学生団体との接点（初期の学生集客の種） ③メディア運営・SEO静的サイト運用の実装ノウハウ（ラグビーマニアで確立済み） ④AI活用による1人開発体制＝開発コスト極小
- **制約**: 営業人員を割けない / 初期投資は最小限 / ツナカレは部活単位登録のため個人単位の学生DBがない

## 3. SWOT 分析

| | プラス要因 | マイナス要因 |
|---|---|---|
| **内部** | **S**: 企業ネットワーク既存保有 / 部活生コミュニティ接点 / SEO・メディア運用ノウハウ / 低コスト開発体制 / 新卒紹介（高単価）への二段階マネタイズ動線を自社内に持つ | **W**: 個人単位の学生DBゼロからのスタート / 営業・CS リソースが薄い / ブランド知名度なし / 口コミ・体験談コンテンツの初期在庫ゼロ |
| **外部** | **O**: 採用直結インターン解禁・就活早期化 / 長期インターン興味層の拡大 / 既存媒体がミスマッチ問題を放置 / 成果報酬・セルフサーブを両立した競合が手薄 | **T**: 大手（マイナビ・リクルート）の本格参入 / 既存媒体の資金力による学生集客競争 / 職業紹介規制の運用変更 / 景況による企業のインターン採用縮小 |

**戦略の骨子**: W（学生DBゼロ）を O（興味層の拡大）× S（SEO/SNSノウハウ）で埋め、S（企業ネットワーク）で初期求人を確保して、コールドスタート問題を両面から崩す。

## 4. STP

### Segmentation
- 学生軸: ①学年（1-2年/3年/引退後） ②志向（成長・キャリア / 収入 / なんとなく） ③所属（体育会・部活 / サークル・学生団体 / 無所属） ④地域（首都圏 / 地方）
- 企業軸: ①目的（新卒採用の入口 / 即戦力） ②規模 ③リモート可否

### Targeting（初期）
- **学生**: 「キャリア意識は芽生えたが、自己分析も業務経験も未着手の大学1〜3年生」を主戦場に、**部活・課外活動に打ち込む学生**を重点セグメントとする。体育会系は「ガクチカ最強層なのに週3〜のコミット要求で長期インターン市場から構造的に排除されている」空白セグメント（03_insights.md §6）であり、**週1〜2・リモート可・オフシーズン設計の求人**を揃えることがツナカレ資産と直結する独自の勝ち筋になる
- **企業**: 新卒採用を見据えて長期インターンを受け入れたいベンチャー〜中堅（成果報酬15万円を許容、採用担当は兼務、東京中心+リモート可求人で地方学生にも供給）

### Positioning
> **「知名度で選ばない。仕事のリアルと自分の志向で選ぶ、長期インターンの意思決定インフラ」**

既存媒体が「求人の量 × 応募の手軽さ」で競うのに対し、当サービスは「情報の解像度 × 期待値の一致」で差別化する。口コミ×求人×軽量自己分析を1つの動線に統合する点が独自性。

## 5. 4P

| P | 内容 |
|---|---|
| **Product** | 構造化求人（採用目的の開示・業務の具体・合わない人の明示）+ 実働経験者のみが書ける口コミ + 軽量志向性診断 + セルフサーブATS。「ミスマッチが起きない」ことをプロダクト仕様で担保 |
| **Price** | 学生: 完全無料 / 企業: 掲載無料・**完全成果報酬 15万円/採用（稼働開始時）+ 稼働開始後30日以内離脱で50%返金【確定】**。リスクゼロ訴求。将来: 上位掲載等のオプション課金余地 |
| **Place** | Web（SEO流入→サイト内完結）+ LINE（学生との継続接点）。企業獲得もインバウンド（「長期インターン 採用」SEO + ツナカレ既存取引先への案内）。営業人員なし |
| **Promotion** | SEOコンテンツ（体験談・職種ガイド・大学別）/ Instagram・TikTok（インターンのリアル発信）/ X・Threads(就活文脈) / 部活・学生団体コミュニティでの紹介 / 口コミ投稿の仕組み自体がコンテンツを再生産する設計。詳細は 06_growth.md |

## 6. ビジネスモデル

```
        求人掲載(無料)                  記事・SNS・口コミ(無料)
  企業 ──────────────→ プラットフォーム ←────────────── 学生
   ↑    採用決定時のみ 15万円/名          個人単位登録・応募
   │                                        │
   └─── ツナカレ既存ネットワークから初期開拓  └─ 3年引退後はツナカレ新卒紹介へ送客
                                              (単価100万円超の二段階マネタイズ)
```

- **単価設計**: 成果報酬 15万円/採用。接点課金はしない（新卒紹介と異なり接点単価1〜2万円が成立しない市場のため）
- **人を介さない**: 求人掲載審査・請求のみ運営が関与（週1人日以内）。営業・キャリアアドバイザーは置かない
- **防御性**: 口コミ・体験談は実働した学生しか書けない＝時間とともに蓄積する参入障壁。SEO資産も同様
- **ツナカレとの整合性**: 本サービスで確立する個人単位アカウントを共通ID基盤とし、①部活生をインターンへ送客 ②インターン経験者を新卒紹介へ送客 ③企業にはインターン(15万)→新卒(100万+)のアップセル、のLTV設計

## 7. 初年度 収支計画（目標: 年商 2,000万円・営業利益黒字）

## 8. リスクと対応

| リスク | 対応 |
|---|---|
| コールドスタート（求人も学生もいない） | 求人: **ツナカレ既存取引先は少数かつ高学歴向けに偏るため主要手段にしない**（使えれば上振れ扱い）。主軸は ①他媒体・自社採用ページで長期インターン募集中の企業を公開情報から特定し、テンプレ化したメール/フォームで「掲載無料・完全成果報酬」を案内するアウトリーチ（営業人員を置かず自動化・定型化で回す） ②企業向けSEO/LPのインバウンド。初期20〜30求人をこの2経路で確保 / 学生: 部活・学生団体接点 + SEO記事の先行公開（Phase 0の序盤をSEO仕込み期間とする） |
| 成果報酬の請求漏れ（媒体外で直接契約される） | 学生側にも稼働報告を求める二重確認 + 規約で直接契約時の報告義務 + 返金規定によって企業が正直に報告するインセンティブを設計 |
| 職業紹介規制 | 実装前に専門家確認（05_requirements.md §7） |
| 年商2,000万円未達 | 損益分岐が低いため事業継続は可能。ツナカレ新卒紹介への送客価値（1名100万円超）を含めた実質LTVで評価する |
