# 08. ブランド戦略 — サブブランド vs 独立ブランドの比較

作成日: 2026-08-20 / ステータス: **決定済み — サブブランド「ツナカレインターン」で確定**（2026-08-20 第5回フィードバック。スカウトDBのツナカレ統合方針は 13_coldstart-usp.md §3 参照）
前提: ツナカレのサブブランド案が第一候補。本資料はその妥当性を事例・SEO・ブランド論の3面から検証する。

---

## 1. HR業界の先行事例から分かること

| 型 | 事例 | 理由（公表・読み取れるもの） |
|---|---|---|
| マスターブランド統一 | マイナビ（全サービスに冠） | マス広告×多角化の相乗効果、認知投資の集中 |
| ブランド借用サブブランド | dodaキャンパス、ビズリーチ・キャンパス、リクナビ薬剤師 | 確立済みブランドの信頼を新領域の初期集客に転用 |
| **本ケースと同型のサブブランド** | **ジョブコミットインターン（HRteam）** | 新卒エージェント運営会社が大学1〜3年向け長期インターンをサブブランドで展開。「将来的な新卒採用母集団の形成」を明示 — **当社構想（インターン→新卒紹介送客）と同型の先行例** |
| 独立ブランド | AMBI（エン・ジャパン）、レバレジーズ各社 | 尖ったターゲット向けに独自の世界観・信頼を専任体制で構築。母体のマス向けイメージから切り離す |
| 独立専業+同一ドメイン内メディア | ゼロワンインターン（01intern.com/magazine/） | サービスサイトとSEOメディアをサブディレクトリで同居 — **サイト構成の実例として参考** |
| 時系列型 | ワンキャリア（ONE CAREER PLUS→2025年「ワンキャリア転職」へ統一） | **「独立気味に立ち上げ→育ってから統一」は実例あり。逆（サブ→独立切り離し）の実例は調査で発見できず** |

教科書的整理: サブブランドの最大メリットは「認知コストの共有」だが、**母体ブランドが確立されていない場合は有効に機能しない**。独立ブランドのメリットは世界観の純度と毀損リスクの隔離、デメリットは認知投資が2重になること。ブランド拡張の成否は「カテゴリフィット×イメージフィット」で決まる。

## 2. SEO観点

- Google公式見解: サブドメインとサブディレクトリは本質同等。ただし「関連コンテンツは同一サイトにまとめるべき」（John Mueller）。実務家の定説は**テーマが近いならサブディレクトリ推奨**（既存ドメイン評価の恩恵が最大）
- 「部活生の就活」と「大学生の長期インターン」は読者・検索意図が近接 → 「大学生キャリア」という上位トピックで**トピカルオーソリティを1ドメインに積める**（同居のプラス）
- ただし: **tunakare.jp の被リンク・流入・指名検索の実測値が小さければ、継承メリット自体がほぼない**。新規ドメインの不利（立ち上げ1年程度）との差が縮む
- ブランドとドメインは分離可能（独立名+既存ドメイン内メディア等）だが、指名検索の育成にはブランド名とURLの一貫性が望ましい

## 3. 本ケースの比較表

| 判断軸 | サブブランド（ツナカレインターン等） | 独立ブランド（新名称・新ドメイン） |
|---|---|---|
| 認知の継承 | ツナカレ認知は部活コミュニティ内に限定的 → **継承メリットは小さい** | そもそも継承するものが小さいため、失うものも小さい |
| カテゴリフィット | ◎ 高い（どちらも大学生キャリア領域） | — |
| イメージフィット | △ 「部活の人向け」という知覚が無所属学生への排除シグナルになる懸念。ただし一般学生はツナカレ自体を知らないため実害は限定的と推測 | ◎ ターゲットに最適化した世界観をゼロから設計できる |
| 送客動線（インターン→新卒紹介） | ◎ 同一ブランド・同一会員基盤で1〜3年→4年の引き上げが自然（ジョブコミットインターン型） | ○ 可能だがブランドをまたぐ同意取得・体験設計のコストが増える |
| 毀損リスク | △ インターン事業の労務・評判リスクがツナカレ本体（企業・大学との信頼が資産）に波及しうる | ◎ 隔離できる |
| 認知投資コスト | ◎ 1ブランドに集中（初期投資最小方針と整合） | △ 2ブランド分。ただし学生の口コミバイラルには覚えやすい専用名が有利な面も |
| SEO | ○ tunakare.jp 同居でトピカルオーソリティ合算（資産実測が前提） | △ 新規ドメインは立ち上がりに時間。ただし既存資産が小さければ差は小さい |
| 後からの変更 | サブ→独立の切り離しは移行コスト大（実例も見つからず） | 独立→統一はワンキャリアの実例あり |

## 4. 推奨と決定前のアクション

### 推奨: **サブブランド（例: ツナカレインターン）で進めて問題なし**。ただし以下の条件付き

1. **学生向けコミュニケーションで「部活生専用ではない」ことを明示する**（コピー・LP・SNSプロフィールで「すべての大学生向け」を打ち出す。部活生は重点セグメントであって限定条件ではない）
2. **評判リスクはプロダクト設計で遮断する**（掲載審査ガイドライン・返金規定・実働者限定口コミ）。これが機能すればツナカレ本体への毀損リスクは許容範囲
3. **ドメインは tunakare.jp のサブディレクトリ or サブドメインを第一候補**とし、実測結果で最終決定する

推奨の根拠: 継承メリットは小さいが、独立ブランドの追加メリット（世界観の純度）も本ケースでは決定打にならず、**2ブランド分の認知投資コストの方が「初期投資最小・営業ゼロ」方針への打撃が大きい**。送客・共通ID基盤との整合はサブブランドが明確に勝る。同型の先行例（ジョブコミットインターン）も存在する。

### 決定前に埋めるべき情報ギャップ（すぐできる・低コスト）
1. **tunakare.jp のドメイン資産の実測**: Search Console / Ahrefs 等で被リンク・オーガニック流入・指名検索量を確認（30分で可能）。資産が想定以上に小さい場合はドメイン新規取得でも失うものはない
2. **簡易認知サーベイ**: 部活非所属を含む大学1〜3年生10〜20人に「ツナカレを知っているか / どんなイメージか」を聞く（ツナカレ=部活イメージが強く出る場合のみ独立ブランドを再検討）
