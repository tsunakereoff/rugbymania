# 03. 学生・企業インサイト調査 — ミスマッチ仮説の検証

調査日: 2026-08-20 / 手法: Web検索（調査データ・就活メディア・Q&Aサイト・プレスリリース）
注: 【データ】（調査機関の定量調査）と【言説】（メディア記事・体験談・Q&Aの声）を区別して記載。重要数値は出典URLで原典確認を推奨。

---

## 0. 検証した仮説

1. 学生は長期インターンに「アルバイト感覚」で応募する（知っている企業か・面白そうか、で判断）
2. 企業は長期インターンを「将来の新卒採用・戦力化」の入口として真剣に見ている
3. その期待値ギャップにより本質的なミスマッチ（早期離脱・採用不成立）が起きている

## 1. 学生が長期インターンを始める動機・選ぶ基準

- 【データ】夏インターン参加目的1位は**「選考優遇をもらうため」23.9%**（ONE CAREER 26卒）。24卒マイナビでは「志望業界を明確にするため」65.6%が最多
- 【データ】キャリアを意識し始めた時期「大学入学以前」73.9%。低学年の9割以上がキャリア支援強化を希望（マイナビ低学年調査）
- 【言説】実際の動機は「バイトより成長できそう」「面白そう」という好奇心ベースが多い。知恵袋には「夏休みをバイトと資格勉強、旅行で終わらせるのは勿体ない気がして…」＝**長期インターンが「バイト・資格・旅行」と同列の選択肢**として天秤にかけられている象徴的な声
- 【言説】「なんとなく就活が不安」「ガクチカがないからとりあえず」動機の応募が頻出課題として語られる

**→ 仮説1は部分的に支持（修正あり)**: 「バイトの上位互換」と「就活の道具（ガクチカ・選考優遇）」の2動機が混在。**どちらも企業が期待する「この会社で戦力になり、あわよくば入社」という動機とはズレている**。動機のズレという仮説の本質は裏付けられた。

## 2. 学生の不安・障壁

- 参加率3〜4%に留まる構造要因: ①学業との両立困難（週15時間程度の稼働要求） ②求人の首都圏偏在 ③長期コミットの負担
- 選考は難関: 採用枠2〜3人/求人、**内定率10%程度**とされ、3〜5社以上の並行応募が推奨される
- 不安の正体は「業務についていけるか」「働くイメージが持てない」。メディアの定番回答は「企業は即戦力を期待していない」
- **「怪しい企業に搾取されるのでは」という警戒感**が応募障壁（最低賃金割れ・テレアポ地獄・やりがい搾取への警告記事が多数流通）
- 地方在住は最大級の障壁（「長期インターンをするなら東京に行く」という構造）

## 3. 離脱・ミスマッチの実態

- 【重要な発見】**長期インターンの早期離脱率を示す信頼できる公的統計は存在しない**（データ空白）。「参加者の8割が途中離脱」という言説が流通するが出典不明
- 【言説】辞める理由の定番: ①説明された業務と実際の乖離 ②テレアポ等の単純作業ループで成長実感なし ③目的意識のないまま焦って開始 ④学業・就活との両立困難 ⑤入社前ギャップによるストレス
- 【データ】長期インターン活用の代名詞キュービックですら**10年間で約700人のインターン輩出→社員入社34人（約5%）**。最も本気の企業でも転換率はこの水準
- 【データ・裏面の証拠】経産省・文科省検討会（2019年度）の企業事例では「長期インターン経験者の入社後離職者0名。良い点・悪い点を両方理解し覚悟を持って入社する」→ **うまく機能すれば長期インターンは最強のミスマッチ削減装置（RJP）になる**

**→ 仮説3は支持（ただし定量データは薄い）**。データ空白自体が、自社調査を行えば一次データホルダーになれる機会。

## 4. 企業側の不満・課題

- 【データ】採用目的でのインターン実施 23.2%（17卒）→**62.8%（26卒）**、採用者の36.3%がインターン経由（就職白書2026）→ **仮説2は強く支持**
- 【言説】企業側の定番課題: ①**途中離脱**（業務計画の変更を余儀なくされる） ②**教育コスト**（既存社員の負担、効果が出るまで生産性低下） ③**採用に繋がらない**（続くとプログラム存続が問われる） ④成果の不確実性
- 【言説】**ドタキャン問題**: 応募者の5割以上が欠席するケースも（中小・BtoB企業で顕著）。ココシロが「面談すり合わせ→当日欠席が起こりにくい」を企業向けセールスポイントにしていること自体が業界共通の痛点の証拠
- 【対称性・重要】ミスマッチの責任は学生の「アルバイト感覚」だけではない。**「人手不足を補う安価な労働力」として学生を扱う企業が混在**し、それが「怪しい・搾取」という学生側の警戒を生み市場全体の信頼を毀損している

## 5. 学生の情報行動

- 【データ】就活生の63%が企業SNSをチェック（Instagram 40.4% / YouTube 36.1% / X 35.1%）。Z世代SNS利用率: YouTube 86.1% / LINE 85.8% / Instagram 71.6% / X 66.8% / TikTok 52.8%
- 【データ】採用動画に求めるのは「かっこよさ」より**「身近さ・リアルさ」**
- 【言説】情報行動の入口は Google検索×就活メディア（Renew Magazine等）+ 知恵袋。「意味ない」「怪しい」「辞めたい」等ネガティブ検索が大量のSEO記事を生んでいる
- 【言説】就活系YouTubeは「しゅんダイアリー」（登録33万人）等が存在するが、**「長期インターン専門」の大型インフルエンサーは不在＝発信の空白**

## 6. 体育会系・部活生をめぐる言説

- 強み: 長期目標へのコミット、組織適応力、回復力、チーム力 → 不動産・金融・商社・メーカー等で人気。「体育会出身者の3年以内離職率は一般の約半分」という言説も（出典不明・言説扱い）
- 弱み: ①**圧倒的な時間不足**（週6練習・4年生も現役・長期休暇は合宿）②強みの言語化ができていない
- 「長期インターンは週3〜・数ヶ月コミットが必要で部活生には難しい。短期・オフシーズン活用が現実解」が体育会向けメディアの共通見解

**→ 体育会系は「ガクチカ最強層なのに、時間制約で長期インターン市場からほぼ排除されている」構造的空白。週1〜・リモート可・オフシーズン設計の求人はこの層への明確な訴求点**（現状はCOMPUSの「週2〜」等の部分対応のみ）。ツナカレの部活生基盤と直結する事業機会。

## 7. ミスマッチを減らす仕組みの事例

| 仕組み | 事例 | 要点 |
|---|---|---|
| 口コミの透明化 | Voil | 338件の口コミ統計分析で「**総合満足度と最も相関するのは業務内容や教育制度ではなく『居心地・フィット感』**」「研修の有無より『質問を丁寧に返してくれる』ことが満足度と相関」 |
| 事前すり合わせ | ココシロ | アドバイザー面談で役割期待・条件を応募前にすり合わせ → 当日欠席減・面接実施率向上 |
| 地理的ミスマッチ解消 | COMPUS | 地方学生×リモート特化 |
| お試し就業・タスクベース選考 | ワークサンプルテスト等 | 実業務に近い課題・半日〜1日の就業体験で相互確認 |
| リアルな仕事体験コンテンツ | moovy・しゅんダイアリー | 社風・働く人の顔を動画で開示。「身近さ」が評価される |
| 制度の後押し | 三省合意改正（タイプ3） | 採用直結を隠さず設計でき、建前と本音の乖離が縮小する方向 |
| 公的エビデンス | 経産省検討会 | 長期インターン経験者の入社後離職0名事例 |

**特に示唆的なVoilの分析**: ミスマッチの核心は求人票に書ける「業務内容・待遇・研修」ではなく、**求人票に書けない「居心地・質問への向き合い方」**にある。つまり現行の求人情報フォーマット自体がミスマッチを構造的に再生産している。

## 8. 総括 — 仮説検証の結論

| 仮説 | 判定 | 要点 |
|---|---|---|
| 1. 学生はアルバイト感覚で応募 | **部分的に支持** | 実像は「バイトの上位互換」+「就活の道具」の2動機混在。いずれも企業期待とズレる点は仮説通り |
| 2. 企業は新卒採用・戦力化の入口として真剣 | **強く支持** | 採用目的実施23%→63%、採用者の36%がインターン経由。ただし「安価な労働力」目的の企業も混在 |
| 3. 期待値ギャップによるミスマッチ | **支持（定量は空白）** | 逸話・言説は大量。公的統計は不在＝一次調査の機会。設計次第で解消可能（経産省事例） |

### 事業への示唆（3点）
1. **ギャップは「入口の言葉」から始まる**: 同じ「長期インターン」という言葉を、学生は「バイト上位互換/就活の道具」、企業は「採用候補の青田買い」として使っている。応募前に役割期待を翻訳・すり合わせる仕掛け（構造化求人・診断・口コミ・タスクベース選考）が有効
2. **求人票に書けない情報（居心地・上司の関わり方）が満足度を決める** → 口コミ項目設計はここを狙う
3. **体育会系×長期インターンは構造的空白** → 低稼働・オフシーズン設計でツナカレ資産と接続
